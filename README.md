# 📚 Research Paper Assistant (RAG + Gemini)

An AI-powered Research Paper Assistant built using Retrieval-Augmented Generation (RAG), FAISS Vector Search, Sentence Transformers, and Google's Gemini API.

The application allows users to:
- Search and process research papers from arXiv
- Generate summaries
- Retrieve related papers
- Ask contextual questions using RAG
- Interact through a Streamlit interface

---

# 🚀 Features

✅ Fetch research papers from arXiv  
✅ Generate concise summaries  
✅ Retrieve semantically related papers  
✅ PDF text extraction and chunking  
✅ Vector embeddings using Sentence Transformers  
✅ FAISS-powered semantic search  
✅ Gemini-powered question answering  
✅ Conversational chat history  
✅ Interactive Streamlit UI  

---

# 🛠️ Tech Stack

- Python
